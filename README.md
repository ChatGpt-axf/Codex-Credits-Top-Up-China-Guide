## 四、Credits 和 Plus / Pro 有什么区别？

这是很多新用户容易搞混的地方。

### Plus / Pro

属于 ChatGPT 套餐。

主要决定：

- 套餐功能
- 包含的使用量
- 可使用的高级功能
- 不同模型和工具的访问范围

### Credits

更像额外使用额度。

当符合条件的功能达到套餐自带限制后，可以继续消耗 Credits。

所以：

```text
Plus / Pro
≠
Codex Credits
```

也可以理解为：

```text
套餐 = 基础使用权限

Credits = 部分功能额外使用量
```

## 九、Codex 额度为什么消耗有快有慢？

不同任务消耗并不完全一样。

官方说明，Codex 使用量可能受到模型、任务复杂度、上下文长度、推理程度、运行位置和工具调用等因素影响。

例如：

```text
修改一个小函数
```

和：

```text
分析大型项目
+
修改几十个文件
+
运行测试
+
反复修复
```

消耗显然不是同一个级别。

所以不要单纯用“用了多少次”判断 Credits 消耗。
